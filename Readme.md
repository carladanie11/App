# Análisis del Sector de Telecomunicaciones en Argentina

Esta aplicación analiza datos del sector de telecomunicaciones en Argentina utilizando Streamlit.

## Funcionalidades

- **Penetración del Servicio**: Análisis de accesos por cada 100 hogares en diferentes provincias.
- **Calidad y Velocidad**: Análisis de velocidades promedio de internet por provincia.
- **Tecnologías de Conexión**: Análisis de las tecnologías de conexión por localidad.
